## Что не закрывается этим релизом

Полная физическая/пространственная проверка ограничений и совместимости, достоверные показатели эффективности, вероятностные модели, ретроспектива, сценарии, 3D, realtime collaborative editing и все возможные требования enterprise-заказчика. Не заменять их демонстрационными баллами. В карте/отчёте различать «не проверено» и «конфликтов не обнаружено проверенным алгоритмом».

Исходная Spec 03 предлагает более широкий результат, включая spatial evaluation и остаточный риск. Этот пакет — явно ограниченная реализационная итерация; не стирать исходную спецификацию и не выставлять «ТЗ полностью выполнено».

## Поля для заполнения кодером в tracker/knowledge-base

Requirement ID; FRC; existing ticket; source status; repository; implementation SHA; test command; test result; environment; evidence artifact; reviewer; acceptedAt. Пустые доказательства не допускают status=accepted. В текущем пакете фактические SHA будущих PR, ответственные люди и результаты проверок не выдуманы.
